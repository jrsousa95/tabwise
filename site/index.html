How it worksComo funciona

Each terminal keeps an append-only event log. Syncing — between terminals on the LAN or with the cloud — means exchanging and merging logs, ordered by a Hybrid Logical Clock, with deterministic conflict resolution. The same sync engine runs on the desktop and on the server. Cada terminal mantém um log de eventos append-only. Sincronizar — entre terminais na LAN ou com a nuvem — é trocar e mesclar logs, ordenados por um Hybrid Logical Clock, com resolução de conflito determinística. O mesmo motor de sync roda no desktop e no servidor.

InstallingInstalação

Windows
  1. Download and run Tabwise-windows-x64-setup.exe.
  2. Baixe e execute Tabwise-windows-x64-setup.exe.
  3. The installer isn't code-signed yet, so SmartScreen may warn you: click More info → Run anyway.
  4. O instalador ainda não é assinado, então o SmartScreen pode avisar: clique em Mais informações → Executar assim mesmo.
  5. Open Tabwise and create the first (owner) staff member.
  6. Abra o Tabwise e cadastre o primeiro operador (dono).
macOS
  1. Open Tabwise-macos-arm64.dmg and drag Tabwise to Applications.
  2. Abra Tabwise-macos-arm64.dmg e arraste o Tabwise para Aplicativos.
  3. The app isn't notarized by Apple yet. On first launch, if macOS blocks it, go to System Settings → Privacy & Security → Open Anyway.
  4. O app ainda não é notarizado pela Apple. Na primeira abertura, se o macOS bloquear, vá em Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim.
  5. If it says the app "is damaged", run xattr -cr /Applications/Tabwise.app in Terminal and open it again.
  6. Se aparecer que o app "está danificado", rode xattr -cr /Applications/Tabwise.app no Terminal e abra de novo.
